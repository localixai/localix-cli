llx is a coding agent for the terminal. It reads and edits files, runs commands, and drives a real browser whose clicks and typing a small decision model does, so the agent itself spends its tokens on thinking.

At a terminal, llx opens a session, and every command, edit and browser action is shown before it runs. In scripts and CI, llx exec runs one task and exits, with the answer alone on stdout and JSON events with --json.

It is one synchronous Rust binary, with no runtime and no plugins. It works with OpenAI's models on your ChatGPT plan or any model on OpenRouter, and reads your project's AGENTS.md. It installs as llx and lx; sign in with /login in a session, or set OPENROUTER_API_KEY.
