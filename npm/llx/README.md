# llx

The agent runtime other agents build on: helpers on any model, decisions for scripts and CI, and a minimal agent for the terminal, in one native binary. This package
installs it for your platform (macOS arm64 and x64, Linux x64).

```bash
npm install -g @localixai/llx     # then: llx
```

Another agent (Claude Code, another agent, a script) calls llx from its shell: `llx exec` for a helper
on any model, `llx decide` for a quick choice.

Docs: <https://github.com/rsaryev/llx>
